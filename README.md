# DanceStudio Manager

## Opis projektu

DanceStudio Manager to aplikacja desktopowa tworzona w języku C# z wykorzystaniem technologii WPF. Jej celem jest ułatwienie zarządzania małą szkołą tańca.

Aplikacja będzie umożliwiać przechowywanie informacji o tancerzach i grupach tanecznych, planowanie zajęć, rejestrowanie obecności oraz kontrolowanie opłat.

## Główne funkcje

- Zarządzanie tancerzami.
- Tworzenie i edytowanie grup tanecznych.
- Planowanie grafiku zajęć.
- Rejestrowanie obecności.
- Kontrolowanie statusu płatności.

## Technologie

- C#
- WPF (Windows Presentation Foundation)
- SQLite
- Entity Framework Core
- xUnit
- Git i GitHub

## Cel projektu

Projekt realizowany jest w ramach nauki programowania. Jego celem jest rozwijanie umiejętności tworzenia aplikacji desktopowych, programowania obiektowego, pracy z bazą danych oraz testowania oprogramowania.

## Status projektu

Projekt jest na etapie przygotowania dokumentacji i planowania kolejnych etapów realizacji.
